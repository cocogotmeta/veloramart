1. Pehle yeh samajh lo

Website 3 layers ki hoti hai. Yaad rakhne ka trick:

HTML Haddi / skeleton. Likhta hai: yeh heading hai, yeh button hai, yeh image hai.
CSS Kapray / look. Color, size, gap, center.
JavaScript Harkat. Click pe kuch ho, number change ho, message aaye.
File names: page ka naam index.html rakho. Style style.css. Logic script.js. Pehle sirf ek HTML file se start karo.

    3. CSS — sundar banana

    Formula hamesha yehi hai:

    selector {
  property: value;
}

    Matlab: kis cheez ko change karna hai, kya change karna hai.

    h1 {
  color: darkgreen;
  text-align: center;
}

p {
  font-size: 18px;
}

body {
  background: #f6f1e8;
  font-family: Arial;
}
